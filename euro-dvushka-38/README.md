# Евродвушка 38,6 м² — дизайн-проект

Перепланировка однокомнатной квартиры (гостиная 19,30 · кухня 9,57 · прихожая 5,13 ·
ванная 4,23 · лоджия 3,84 м²) в евродвушку: спальня 9,7 м² у окна + кухня-гостиная.
Стиль: современный минимализм со скандинавскими акцентами, эконом-бюджет.

- `geometry.py` — геометрия квартиры, стены, проёмы, мебель (единый источник для всех схем)
- `draw.py` — отрисовка планов и изометрии в SVG
- `build_deck.py` — сборка схем и слайдов: `python3 build_deck.py <папка_слайдов> schemes`
- `schemes/` — 17 схем в SVG: обмер, демонтаж, монтаж, план после, мебель, хранение,
  водоснабжение, канализация, розетки, освещение, 7 видов 3D
- `deck/` — слайды презентации (26 шт.)

Размеры сняты с маркетингового плана без размерной сетки и уточняются обмером.
Чтобы перестроить все схемы, достаточно поправить `geometry.py`.
